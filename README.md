# Aurea: el museo de los enigmas

Juego web de enigmas: 100 obras repartidas en 9 salas. Ordena las letras, identifica
al artista y la obra, y desbloquea un fondo exclusivo para el móvil.

**Jugar:** https://magodago.github.io/aurea/

## Estructura

- `index.html`, `main.js`, `main.css` — build estático listo para servir.
- `assets/` — 100 imágenes de obra + 10 pistas musicales y fondos.
- `codigo-fuente/` — proyecto React + Vite original (fuente, sin `node_modules`).

Sitio servido por GitHub Pages desde la rama `main`, raíz del repositorio.
